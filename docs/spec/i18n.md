> 状态：**框架已就位，尚未接管客户端文案**。`client.js` 必须保持为「零依赖单文件浏览器模块」，因此本次不改动 `client.ts` 的内联字典；迁移方式见 §5。

## 1. 目标与边界

- 提供**类型安全、可测试、与宿主解耦**的翻译内核。
- 语言资源集中管理，避免中英文散落在事件回调与 DOM 构造里。
- 支持 DSH `ctx.locale` 服务；宿主没有该服务时自动降级为本地字典，绝不让 UI 因 i18n 崩溃。
- 本次只交付：类型、翻译内核、语言资源、宿主注册适配层、打包声明、单元测试与本文档。**不改变任何现有运行时行为**。

## 2. 目录结构

```text
packages/server/
├── locale/
│   ├── en.json              # Plugin Manager 元数据 + 面板文案（打包产物）
│   └── zh-CN.json
└── src/i18n/
    ├── types.ts             # LocaleId / CatalogSet / Translate / LocaleServiceLike
    ├── core.ts              # normalizeLocale / formatMessage / createI18n
    ├── catalog.ts           # 语言资源唯一事实来源（TS 常量，浏览器安全）
    ├── cordis.ts            # bindCordisLocale / getLocaleService
    └── index.ts             # 对外统一出口（`@dsh-hid/...` 的 ./i18n 子路径）
```

`locale/*.json` 与 `catalog.ts` 内容必须一致，`test/i18n.test.ts` 会做深度相等的漂移校验。

## 3. 使用方式

### 3.1 纯函数 / 任何环境（含浏览器单文件）

```ts
import { createI18n, PERIPHERAL_CATALOGS } from 'dsh-plugin-peripheral-server/i18n';

const i18n = createI18n({ catalogs: PERIPHERAL_CATALOGS, locale: 'zh-CN' });
i18n.t('status.RUNNING');                 // 运行中
i18n.t('slot.usage', { index: 3 });       // 若目录中有 `slot.usage: 'Slot {index}'`
i18n.t('unknown.key');                    // 原样返回 key
i18n.setLocale('en-US');                  // -> 'en'
```

### 3.2 宿主内部（Cordis）

```ts
import {
  bindCordisLocale,
  getLocaleService,
  PERIPHERAL_CATALOGS,
  PERIPHERAL_NAMESPACE,
} from 'dsh-plugin-peripheral-server/i18n';

const binding = bindCordisLocale(
  getLocaleService(ctx),
  PERIPHERAL_NAMESPACE,
  PERIPHERAL_CATALOGS
);
binding.t('title');        // 宿主 bind 成功时跟随用户语言，否则回落到本地 en
binding.dispose();         // 插件卸载时释放注册（务必放入 disposers）
```

行为约定：

- 注册 `en`、`zh-CN`，并为带地区的语言自动注册基语言别名（`zh`）。
- `register` / `bind` 抛错仅影响该语言，`t` 始终可用。
- `registered` / `bound` 暴露给诊断与测试，不要在业务逻辑里分支。

## 4. 文案键规范

| 前缀 | 用途 |
| --- | --- |
| `meta.*` | Plugin Manager 卡片标题 / 描述（`meta.title`、`meta.description`） |
| `status.*` | `AgentPeripheralStatus` 枚举值到可读文案的映射 |
| 其余扁平键 | 面板通用文案（`title`、`slot`、`session`…） |

新增语言：在 `LocaleId` 联合类型中加入 id → 在 `catalog.ts` 补一份全量字典 → 在 `locale/` 补镜像 JSON → 跑测试。
