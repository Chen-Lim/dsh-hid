# i18n 多语言国际化系统

> 状态：**已全量接入（服务端 + 客户端 + 官方规范对齐）**。支持英语（`en`）与中文（`zh` / `zh-CN`），满足 DSH 插件管理器发现规范与端侧面板无感即时切换。

---

## 1. 目标与设计规范

- **官方规范对齐**：完全遵循 DSH 官方国际化架构（基准语言 `zh` 与 `en`）。
- **元数据发现兼容**：在 `locale/en.json` 与 `locale/zh.json` 中提供标准 `meta: { title, description }` 结构，确保 DSH `readPluginMeta` 能无缝解析插件中英文展示卡片。
- **全链路动态响应**：
  - 服务端：`PeripheralServerService` 通过 `bindCordisLocale` 注册 `peripheral` 命名空间并管理生命周期。
  - 客户端：`client.ts` 监听 `ctx.locale.subscribe` 与 `locale/change` 事件，当用户在 DSH 设置中切换语言时，侧栏与主面板无需刷新即可即时热重渲染。
  - 优雅降级：宿主无 `ctx.locale` 时，通过 `navigator.language` 自动降级为本地字典，保证脱机或独立环境中零报错。

## 2. 目录结构与资源映射

```text
packages/server/
├── locale/
│   ├── en.json              # DSH Plugin Manager 元数据 + 英文词典
│   ├── zh.json              # 官方基准中文词典（zh）
│   └── zh-CN.json           # BCP 47 区域别名词典
├── README.md                # 官方英文文档
├── README.zh.md             # 官方中文文档
└── src/
    ├── client.ts            # 客户端浏览器伴侣模块（注入 locale，监听切换）
    ├── service.ts           # Cordis 服务端插件入口（bindCordisLocale）
    └── i18n/
        ├── types.ts         # LocaleId ('en' | 'zh' | 'zh-CN') / MessageCatalog
        ├── core.ts          # 归一化语言协商、占位符插值与嵌套/扁平属性查找
        ├── catalog.ts       # 语言资源唯一事实来源（EN_MESSAGES / ZH_MESSAGES）
        ├── cordis.ts        # bindCordisLocale / getLocaleService
        └── index.ts         # 统一出口
```

`locale/*.json` 与 `catalog.ts` 内容保持 1:1 同步，由单元测试 `test/i18n.test.ts` 进行自动化防漂移校验。

## 3. 运行时行为与交互

### 3.1 服务端（Cordis Service）
插件加载时自动提取宿主 `ctx.locale`，调用 `bindCordisLocale` 进行多语言字典注入并双向建立 `zh` ⇄ `zh-CN` 别名映射。当插件销毁时自动调用 `dispose()` 释放注册槽位。

### 3.2 客户端伴侣（Browser Companion Plugin）
1. **词典注入**：在 `apply(ctx)` 中将 `peripheral` 命名空间注册至 `ctx.locale`。
2. **实时订阅**：订阅 `locale.subscribe`，语言变更时触发内部 store 通知，驱动 React 树（`PeripheralPanel` 与 `PeripheralIcon`）就地重新渲染。
3. **侧栏常驻槽位**：`sidebar.panellist` 注册配置携带 `locale: 'peripheral'`，其 `label` 使用动态 Thunk `() => t('title')`，随系统语言切换自动更新文案。

## 4. 词典键规范

| 键名 | 英文 (`en`) | 中文 (`zh`) | 用途说明 |
| --- | --- | --- | --- |
| `meta.title` | `Peripheral` | `外设` | 插件管理器标题 |
| `meta.description` | `Physical slot status reported by the peripheral bridge.` | `由外设桥接服务上报的物理槽位状态。` | 插件管理器描述 |
| `title` | `Peripheral` | `外设` | 侧栏标签与主面板标题 |
| `subtitle` | `Physical slot status reported by the peripheral bridge.` | `由外设桥接服务上报的物理槽位状态。` | 主面板副标题说明 |
| `connected` | `Bridge connected` | `桥接已连接` | 桥接在线状态 |
| `disconnected` | `Bridge offline` | `桥接未连接` | 桥接离线状态 |
| `slot` / `session` / `status` / `tool` | `Slot` / `Session` / `Status` / `Tool` | `槽位` / `会话` / `状态` / `工具` | 物理槽位监控表头 |
| `error` | `Connection error. Retrying…` | `连接异常，正在重试…` | 连接异常告警 |
| `status.*` | `Inactive` / `Running` / `Needs input` / ... | `未使用` / `运行中` / `等待输入` / ... | 状态机可读文案映射 |
