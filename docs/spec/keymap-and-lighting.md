# 按键与视觉映射规范 (Keymap & Lighting Specification)

## 1. 物理外设定位与交互理念

物理键盘并非替代全部终端交互，而是作为 Agent 协作的**边缘状态监视屏**与**高频物理快控面板**：
- **边缘视觉监控（Peripheral Vision）**：开发者无需切屏即可通过余光从 F1-F12 按键的独立背光感知 12 个 Agent 任务的运行状况。
- **瞬时焦点切换（One-Touch Switching）**：通过 FN2 快捷层直接跳至对应任务窗口或控制上下文。
- **触觉调参（Tactile Tuning）**：利用机械旋钮细腻调节模型思考深度。

## 3. F1-F12 槽位与单键 RGB 状态指示

### 3.1 状态枚举与灯光行为
每个按键的 RGB LED 独立映射一个对应 Agent 槽位：

| 状态枚举 (`SlotStatus`) | 触发条件 | 视觉反馈（推荐） | 物理按键 (FN2) 动作 |
| --- | --- | --- | --- |
| `INACTIVE` | 该槽位未绑定任何活跃 Session | **关闭 (LED OFF)** / 随键盘全局背景光 | 若按下，提示无对应 Session |
| `IDLE` | Agent 存在，当前处于待机状态 | **微光白 / 浅绿常亮** (亮度 30%) | 切换当前控制焦点至该 Agent |
| `RUNNING` / `THINKING` | 模型正在流式推理或正在执行工具 | **蓝色呼吸 / 跑马流动** | 切换焦点或查看该 Agent 运行流 |
| `NEEDS_INPUT` | Agent 触发问答提问或等待确认 | **琥珀橙色高频脉冲 (Pulse)** | 切换焦点并高亮等待输入 |
| `COMPLETED` | 当前轮次执行完成 | **鲜绿色常亮 3 秒**后回到 `IDLE` | 切换焦点审阅结果 |
| `ERROR` | 执行抛错、API 失败或中断 | **红色快闪 3 次**后保持微弱红光 | 切换焦点排查错误日志 |

### 3.2 焦点指示 (Focus Indicator)
当前在 DSH CLI 或 IDE 中处于激活状态（Focused）的 Agent，其对应的 F 键会呈现高亮度常亮或伴随周边灯光的辅助标识，区别于非焦点但运行中的 Agent。

## 4. 旋转编码器（Knob / 旋钮）控制规范

旋钮负责调节当前聚焦 Agent 的思考预算（Brainpower / Reasoning Effort）：

| 物理动作 | 对应指令 | 效果说明 |
| --- | --- | --- |
| **顺时针旋转 (CW)** | `knob/stepUp` | 提升一档思考预算（例如：`low` -> `medium` -> `high` -> `max`） |
| **逆时针旋转 (CCW)** | `knob/stepDown` | 降低一档思考预算（例如：`high` -> `medium` -> `low`） |
| **单次按下 (Press)** | `knob/press` | 触发紧急中断（Panic Abort）或重置为当前模型默认强度 |

---

## 5. 快速响应与选项按键映射 (Quick Response Keys)

当当前聚焦的 Agent 触发交互选择（例如 `user-questions` 提出多选项，或需要确认动作）时，外设按键可快速响应：

### 5.1 选项映射
- **按键 1**：选择选项 1（Option 1）。
- **按键 2**：选择选项 2（Option 2）。
- **按键 3**：选择选项 3（Option 3）。
- **按键 4**：自定义输入（聚焦终端输入框）。

### 5.2 决策审批快捷按键
- **Enter / 'Y' 键**：快速确认（`ACCEPT` 放行当前操作）。
- **Esc / 'N' 键**：快速拒绝（`REJECT` 阻断当前操作）。
- **'A' 键**：总是允许本会话内的该类工具（`ALWAYS_ALLOW`）。
